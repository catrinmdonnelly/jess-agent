# Image prompt library

*The visual style for slide-2 illustrations. Jess uses this to anchor every image brief, so what you put here decides how the daily images actually look.*

## Visual style summary

Replace this with two to three sentences describing the image style. Examples:

- "Watercolour illustrations. Lived-in, never flat-lay. Human presence welcome. Soft edges, muted palette."
- "Documentary-style photography. Real environments, available light, slight desaturation."
- "Hand-drawn line illustration. Black ink on warm cream. Minimal, single subject per frame."
- "Bright editorial photography. Single bold colour against neutral background. High contrast."

The more specific, the better.

## Always include

Replace this with elements that should be in every image, if any. Examples:
- A specific colour that always appears
- A small recurring object (a coffee cup, a notebook, a plant)
- A consistent lighting feel (golden hour, overcast, fluorescent)

## Never include

Replace this with hard nos. Examples:
- No text in the image (Jess defaults to this, the hook card carries the text)
- No logos or brand marks
- No celebrities or recognisable real people
- No firearms / alcohol / specific things that don't fit your brand
